## 4 周复习计划

按每周 5 天学习、1 天实践、1 天复盘安排；可按已有基础调整。每日建议完成“读一个知识点、口述两道题、记录一个不确定点”。

| 周次 | 学习范围 | 实践 | 验收方式 |
| --- | --- | --- | --- |
| 第 1 周 | 数学、分词、NLP、Transformer、Embedding | 手写 Softmax 与因果 Attention | 写出张量形状，证明未来 token 不影响前缀输出 |
| 第 2 周 | 数据、预训练、SFT、LoRA、DPO/GRPO | 设计一份可复现的微调方案 | 推导 LoRA 参数量、解释 loss mask，估算训练状态 |
| 第 3 周 | 分布式、推理、RAG、上下文与工具 | 运行检索指标，设计 RAG 分层诊断 | 计算 KV Cache，区分召回与生成错误 |
| 第 4 周 | 评测、系统设计、项目复盘 | 完成项目卡片与两轮模拟面试 | 能说明基线、个人贡献、消融、失败与限制 |

## 面试前自查

- [ ] 能在纸上写出 Attention、交叉熵、LoRA、DPO 的变量与适用条件。
- [ ] 能估算一次训练状态和一次 KV Cache，区分 GB、GiB 与真实峰值。
- [ ] 能说明自己项目的数据划分、测试集隔离及评测指标。
- [ ] 能讲清一个失败案例，拿出日志或对照实验支持归因。
- [ ] 能回答“换一个方案为什么不行”“成本增加多少”“如何回滚”。
- [ ] 能独立实现一种核心算子或评测指标，并解释空输入、重复项等边界。
- [ ] 项目数字与职责均来自真实经历，不熟悉的内容明确标记待补。

只剩 3 天时，优先复习 [P0 题目](question-bank.md)、[公式速查](cheatsheet.md) 和自己的项目；保留一次完整口述演练。
