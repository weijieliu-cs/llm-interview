# 03 预训练与数据

[返回首页](../README.md) · [题目索引](question-bank.md)

## 核心知识

预训练不是只选择模型大小。应同时定义数据来源、分词器、训练目标、计算预算、评测集和恢复策略。

对自回归序列 $x_{1:S}$：

$$
\mathcal L_{\mathrm{CLM}}=-\sum_{t=2}^{S}\log p_\theta(x_t\mid x_{<t}).
$$

工程实现常用 logits 的前 $S-1$ 个位置对齐标签的后 $S-1$ 个位置；有些框架在内部 shift，重复 shift 会训练错位。padding、跨样本边界和有效 token 的归约都需明确。

## 常见面试题

<a id="p01"></a>
### P01｜CLM、MLM 和去噪目标有什么区别？【P0】

**回答要点：** CLM 从前缀预测后续 token，训练和自回归生成形式一致；MLM 利用双向上下文恢复被遮盖位置，适合表示学习；去噪序列到序列目标从破坏的输入恢复原始文本。目标决定可见信息和损失位置，不应只根据模型名称判断训练方式。

**追问：** 为什么 teacher forcing 仍能并行？训练时真实前缀已知，可一次前向得到所有位置预测；生成时新 token 依赖先前生成结果。

<a id="p02"></a>
### P02｜如何设计预训练数据治理流程？【P0】

**回答要点：** 建立来源与使用权限清单，经过解析、语言识别、规则及质量过滤、敏感信息处理、精确与近似去重、评测污染检查，再确定混合比例。按来源、时间和文档簇划分验证集，保留数据版本与各阶段样本量。过滤后还需抽样检查，避免系统性删除某些语言或领域。

**追问：** 为什么去重不等于消除污染？改写、翻译和题解片段可能绕过文本匹配；需要结合来源隔离、语义相似度及人工审查。数据风险实例见 [RealToxicityPrompts](https://arxiv.org/abs/2009.11462)。

<a id="p03"></a>
### P03｜固定算力预算下如何选择参数量和训练 token 数？【P1】

**回答要点：** 稠密 Transformer 的训练 FLOPs 常粗略估计为 $C\approx6ND$，其中 $N$ 为参数量、$D$ 为训练 token 数；该式忽略部分注意力、嵌入及实现开销。Scaling Law 用经验拟合指导预算分配，Chinchilla 强调同时扩大模型与数据。实际选择还取决于数据质量、部署成本和推理负载。见 [Training Compute-Optimal Large Language Models](https://arxiv.org/abs/2203.15556)。

**追问：** 是否永远用固定的 token/参数比例？不是。训练最优与生命周期成本最优可能不同，公式中的经验比例也依赖拟合范围和数据分布。

<a id="p04"></a>
### P04｜训练突然出现 loss spike 或 NaN，怎么排查？【P0】

**回答要点：** 先记录首次异常的 step、数据批次、梯度范数、学习率、精度与各 rank 日志。复现问题批次，检查非法标签、全掩码注意力、异常序列、溢出和通信错误，再对照最近的代码、数据或配置变更。逐步降低学习率或使用更稳定的数值路径，不应无证据地同时修改多个变量。

**追问：** BF16 是否彻底避免溢出？它的指数范围比 FP16 更大，但尾数精度、累加方式及中间算子仍会导致数值问题。

<a id="p05"></a>
### P05｜如何把短上下文模型扩展到更长上下文？【P1】

**回答要点：** 检查位置编码与缩放方案，引入长序列数据并设计长度课程，结合内存优化控制训练成本。评测应覆盖远距离检索、多跳聚合、位置敏感性以及短上下文回归。仅修改配置中的最大长度不会保证模型使用远处信息。位置机制见 [RoFormer](https://arxiv.org/abs/2104.09864)。

**追问：** 通过 needle-in-a-haystack 就足够了吗？它主要检验特定检索能力，不能代替长文总结、跨段推理和多证据一致性评测。

<a id="p06"></a>
### P06｜怎样实现可恢复、可比较的训练实验？【P1】

**回答要点：** 保存模型、优化器、学习率调度、混合精度缩放器（若有）、随机状态、数据游标和分布式配置；记录代码提交、数据与 tokenizer 版本、全局有效 token 数。恢复后验证下一批数据、学习率和损失连续性。

**追问：** 固定随机种子就能逐位复现吗？不能。并行归约顺序、非确定性算子、硬件和库版本也会影响结果；应区分逐位复现与统计上可重复。

## 易错点

- 把训练 step 数作为不同序列长度实验的唯一预算口径。
- 只保存模型权重，却声称可以完整恢复训练状态。
- 只报告整体验证损失，不检查领域与语言子集。
