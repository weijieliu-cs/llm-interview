# 11 经典 NLP、Embedding 与模型比较

[返回首页](../README.md) · [题目索引](question-bank.md)

## 核心知识

从静态词向量、上下文 token 表示到面向检索的句向量，表示学习的目标和粒度不断变化。生成模型的隐藏状态也可构造表示，但不能由维度大小直接推断检索质量。

| 表示方式 | 训练或使用目标 | 需要注意 |
| --- | --- | --- |
| Word2Vec | 预测词与上下文关系 | 同一词通常对应固定向量 |
| BERT token 表示 | 根据双向上下文恢复词 | 表示依赖句子和位置 |
| Bi-encoder 句向量 | 独立编码 query 和文档 | 可预建索引，交互受向量表示限制 |
| Cross-encoder | 联合输入 query 和候选评分 | 细粒度交互，通常不能预缓存独立文档评分 |

## 常见面试题

<a id="n01"></a>
### N01｜Word2Vec 的 CBOW 与 Skip-gram 有什么区别？【P1】

**回答要点：** CBOW 用周围词预测中心词，Skip-gram 用中心词预测上下文词。两者学习静态词表示，可通过负采样等方式降低大词表训练成本；负采样的二分类目标不能直接等同于完整 Softmax 概率。语境中的多义词是静态表示的局限之一。见 [Word2Vec](https://arxiv.org/abs/1301.3781)。

**追问：** 与 LLM 的 token embedding 有什么联系？输入嵌入同样是查表参数，但 LLM 经过上下文层后得到随上下文变化的表示，不能把两者的最终输出视为同一种对象。

<a id="n02"></a>
### N02｜BERT 的 MLM 为什么不直接适合自回归生成？【P1】

**回答要点：** 原始 BERT 利用双向上下文预测被选中的位置，还使用下一句预测任务；自回归生成要求只根据已知前缀逐步建模。二者训练可见信息及目标不同。BERT 可以用在分类、抽取、匹配等任务，但不能仅删除 mask 就获得同等训练充分的因果生成器。见 [BERT](https://arxiv.org/abs/1810.04805)。

**追问：** 取 CLS 就一定是好的句向量吗？不一定。预训练目标未必直接优化余弦语义距离，需要在下游检索或相似度数据上验证。

<a id="n03"></a>
### N03｜如何训练面向检索的 Embedding 模型？【P0】

**回答要点：** 构造 query、正例与负例，用对比目标拉近相关样本、拉远不相关样本。批内负例提高效率，难负例提高区分能力，但需处理假负例和数据泄漏。文本模板、池化、归一化与训练推理一致性都影响效果。双塔句向量的代表工作见 [Sentence-BERT](https://arxiv.org/abs/1908.10084)。

**追问：** 为什么更难的负例不总更好？标错的相关文档可能被当作难负例强行推远，应进行挖掘质量检查和难度控制。

<a id="n04"></a>
### N04｜余弦、内积、欧氏距离什么时候给出相同排序？【P0】

**回答要点：** 当 query 和候选都做 L2 归一化，余弦等于内积，且 $\|u-v\|_2^2=2-2u^\top v$，因此距离升序与相似度降序一致。未归一化时，向量范数也会影响内积和距离。零向量无法按通常定义计算余弦，应明确处理。

**追问：** 向量维度越高越好吗？更高维增加存储和检索成本，质量取决于训练目标、任务分布与索引近似误差，需要实测。

<a id="n05"></a>
### N05｜为什么召回常用双塔，重排常用交叉编码器？【P0】

**回答要点：** 双塔可以离线编码文档并建立近似最近邻索引，适合大规模召回；交叉编码器联合建模 query 与文档，候选级计算成本较高，常用于少量候选重排。两阶段系统把覆盖与精排分开，必须联合观察召回上限和延迟。

**追问：** 换了 Embedding 模型为什么要重建索引？新旧向量空间通常不兼容；维度相同也不意味着距离可比。应版本化模型、模板和索引，支持切换及回滚。

<a id="n06"></a>
### N06｜如何专业地比较不同模型家族与具体版本？【P1】

**回答要点：** 固定具体 checkpoint，比较训练目标、稠密或 MoE、归一化、位置编码、注意力结构、词表、上下文、许可证和后训练方式，再做同任务、同预算测试。可用 [LLaMA](https://arxiv.org/abs/2302.13971) 与 [DeepSeek-V3](https://arxiv.org/abs/2412.19437) 练习阅读结构差异；不要把某一版本的设计泛化到整个家族。

**追问：** 参数更少为何可能更适合业务？领域覆盖、工具能力、延迟、成本和部署约束都可能比总参数量更影响最终价值。

## 易错点

- 把句向量维度、上下文窗口和模型隐藏维度当作同一个指标。
- 更换向量模型后混用旧索引，或只验证公开相似度榜单。
- 用模型家族名代替具体版本、精度和任务设置。
